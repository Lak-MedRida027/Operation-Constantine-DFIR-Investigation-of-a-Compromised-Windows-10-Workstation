# Operation Constantine — Knowledge Graph

Open this folder as an **Obsidian vault** (Open folder as vault), then open
**[[00 - Operation Constantine (MOC)]]** and switch to **Graph View** (Ctrl/Cmd+G).

Node colours (graph view groups):
- red = ATT&CK techniques · orange = malicious artifacts · blue = evidence sources
- pink = entities/hosts · green = analysis notes

Everything is cross-linked so the graph reproduces the attack + investigation relationships.
